Archivo: tests/Unit/ReglasDominioTest.php, línea 54 inicial.
Método: test_etiquetas_de_movimientos_sin_base_de_datos.
Error: Call to a member function connection() on null.

Causa:
El constructor new MovimientoInventario(['tipo' => $tipo]) activa asignación
masiva. Como el modelo usa $guarded = ['id'], Eloquent intenta consultar el
esquema para determinar columnas asignables. En una Unit pura no hay resolvedor
de conexión; el error ocurrió antes de comprobar etiquetaTipo.

Corrección mínima, exclusivamente en la prueba:
$movimiento = new MovimientoInventario;
$movimiento->tipo = $tipo;

No se cambió el modelo, no se creó una BD para esta prueba y no se convirtió
en Feature. La prueba sigue ejecutando el método real.

Resultado posterior:

La evidencia inicial se conservó; no se introdujeron errores intencionalmente.
